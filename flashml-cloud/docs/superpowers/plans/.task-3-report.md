   under the system temp dir (`tempfile.mkdtemp(prefix="flashml-pg-sock-")`)
   while the data directory stays under `tmp_path_factory`; the DSN
   itself connects over TCP (`127.0.0.1:<port>`), so this only affects
   where the server puts its socket file.

   Supabase `auth.users` column set (instance_id, aud, role, email,
   ...), which doesn't exist on the local one-column stub. Fixed by

   including the Supabase-shaped columns that are actually present —
   the same test code now works unmodified against both the local stub
   and, via TEST_DATABASE_URL/DATABASE_URL, the real Supabase schema.
