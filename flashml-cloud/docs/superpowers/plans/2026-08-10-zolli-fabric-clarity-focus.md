# Zolli Compute Fabric Clarity and Focus Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the production Zolli Three.js hero fill its stage, render sharply, and present four source-specific machine categories whose silhouettes remain recognizable across desktop, tablet, and mobile.

**Architecture:** Add deterministic focus, camera, island-emphasis, and render-quality contracts to the existing production fabric model. Plumb one nullable source focus from the DOM controller into the R3F scene, rebuild the five first-party GLBs through the existing deterministic generator, and preserve the existing Canvas boundary, story reducer, inspection bridge, and fallback paths. Independent asset and runtime lanes converge before one measured browser-tuning and verification pass.

**Tech Stack:** Next.js 16, React 19, TypeScript, React Three Fiber 9, Three.js 0.185, Drei, React Three Postprocessing, CSS Modules, Vitest, deterministic Node GLB generation, glTF-Transform, GStack browser QA, and Three.js MCP inspection.

## Global Constraints

- Work in `apps/web` unless a task names a documentation or report path.
- Preserve the exact hero eyebrow, headline, definition, CTA labels, CTA order, source copy, and six story-state labels.
- Do not add dependencies, routes, comparison variants, orbit controls, video, or another canvas.
- Do not reintroduce `/hero-lab`, A2, B2/C comparison labels, or lab imports.
- Keep all five GLBs first-party, deterministic, and generated by `scripts/hero-assets/build-fabric-assets.mjs`.
- All five GLBs and textures must transfer in at most 1.8 MB.
- High desktop must remain at or below 120 conservative calls and 150,000 visible triangles.
- Balanced/mobile must remain at or below 70 calls and 60,000 visible triangles.
- High desktop must sustain at least 55 FPS average; Balanced mobile must sustain at least 50 FPS average.
- High DPR is `[1.25, 2]`; Balanced and Static DPR are `1`.
- High bloom renders at full resolution with intensity `0.26`, smoothing `0.24`, and no device-body participation.
- Source-focus scale is `1.15` desktop/tablet and `1.12` mobile. Focus lift is `0.32` desktop/tablet and `0.28` mobile.
- Desktop focus shifts the target `36%` toward the source and closes distance `13%`; tablet shifts `32%` and closes `8%`; mobile does not move the camera laterally.
- Manual source selection pauses and focuses. Story-step selection and pressing Play clear focus and return to overview.
- Static, reduced-motion, hidden-document, and non-continuous paths snap to complete poses.
- Preserve native DOM controls, `aria-pressed`, `aria-current`, live regions, visible focus treatment, 40-pixel targets, and vertical touch panning.
- Preserve loading, WebGL2-unavailable, context-loss, asset-failure, unmount, and Three-inspection cleanup behavior.
- Do not stage, commit, push, merge, reset, clean the worktree, edit unrelated dirty files, or stop an unknown server process.
- Every task writes its factual report under `.superpowers/sdd/2026-08-10-zolli-fabric-clarity-focus/` and leaves plan checkbox updates to the controller.

- [x] **Step 4: Implement the pure overview and focus math**

Use immutable numeric tuples. Implement the tier table and focus calculation exactly:

```ts
const FABRIC_OVERVIEW_CAMERA = Object.freeze({
  desktop: Object.freeze({ position: [6.7, 5.35, 7.05], lookAt: [0, 0.28, 0], fov: 35 }),
  tablet: Object.freeze({ position: [7.8, 6.4, 8.3], lookAt: [0, 0.28, 0], fov: 40 }),
  mobile: Object.freeze({ position: [9.5, 8.2, 10.5], lookAt: [0, 0.34, 0], fov: 44 }),
} as const);

export function getFabricCameraPose({ viewportWidth, focusedSource }: FabricCameraPoseInput) {
  const tier = viewportWidth < 560 ? "mobile" : viewportWidth < 1024 ? "tablet" : "desktop";
  const overview = FABRIC_OVERVIEW_CAMERA[tier];
  if (!focusedSource || tier === "mobile") return overview;
  const shift = tier === "desktop" ? 0.36 : 0.32;
  const distanceScale = tier === "desktop" ? 0.87 : 0.92;
  const source = FABRIC_SOURCE_LAYOUT[focusedSource].position;
  const lookAt = [source[0] * shift, 0.28 + (source[1] + 0.42 - 0.28) * shift, source[2] * shift] as const;
  const offset = overview.position.map((value, index) => value - overview.lookAt[index]) as unknown as FabricPoint3;
  const position = offset.map((value, index) => lookAt[index] + value * distanceScale) as unknown as FabricPoint3;
  return { position, lookAt, fov: overview.fov };
}
```

Use a small `mapPoint3` helper rather than leaving unsafe casts in the final implementation.

`getFabricIslandEmphasis` returns base scale/Y for non-focused sources and the exact global-constraint scale/lift for the focused source. `getFabricFocusTransition` returns `"snap"` unless `continuous && quality !== "static"`.
