# Task 5 — The API fronts the coordinator

**Status:** complete. Tests 35 → **75 passed, 0 skipped** (40 new, all in
`apps/api/tests/test_agent_proxy.py`). No skips introduced anywhere.

`create_cloud_app(settings, connect, transport)` in `app.py` is the public
door: 12 agent routes (register / heartbeat / claim / attempts×3 /
artifacts GET+PUT / checkpoints×4), 4 browser routes, 2 device-flow routes.
Every agent call resolves `node_id` from the machine token and forwards with
the operator token plus exactly one `X-FlashML-On-Behalf-Of`. `create_app()`
returns this app when `SUPABASE_URL`+`COORDINATOR_URL` are set, the legacy
POC app otherwise — never a mixture.

## Adversarial findings (all fixed, each with a test)

1. **Path traversal out of the artifacts route (real hole).** Starlette
   percent-decodes `{key:path}` and httpx then resolves dot segments, so
   `PUT /v1alpha1/artifacts/..%2F..%2Fleases%2Fclaim` would have reached an
   arbitrary coordinator route carrying the operator credential. `%3F` in a
   key likewise injected a query string. Fixed by `_artifact_key` /`_seg`.
2. **Header injection via `node_id`.** node_id is attacker-supplied at
   device-code time and later becomes a header *value*; CR/LF would be
   request splitting. Validated on entry and again in `forward()`.
3. **Anonymous DB-connection burn.** `current_machine` as a `Depends(db_conn)`
   opened Postgres before any credential check; now the connection is opened
   only after the token is the right shape. Pinned by a counting-factory test.
4. **Unbounded body buffering** by an authenticated volunteer: 1 MiB cap on
   JSON, `FLASHML_MAX_UPLOAD_BYTES` (256 MiB) on artifacts.
5. Duplicate `Authorization` or `X-FlashML-On-Behalf-Of` headers, and
   case-varied spoofs: no inbound header is ever copied outbound.

**Not leaked:** the operator token and internal URL appear in no response,
no log line, and no error — the coordinator-unreachable path returns a bare
502 and does not echo the exception string (tested via caplog). Secrets audit
CLEAN.

## Residual, deliberately not fixed here

- CORS still defaults to `*` (override with `FLASHML_CORS_ORIGINS`). Safe
  today because credentials are Authorization headers, not cookies; worth
  pinning at deploy (Plan 7).
- Artifact reads are authenticated but not yet job-scoped — Task 6.
- Blocking psycopg calls run on the event loop; fine at POC scale, not at
  Render's concurrency.
- The `DELEGATION_HEADER` spelling is kept in sync with `modea.py` by a
  literal-string test, not by import (dependency rule: protocol only).
